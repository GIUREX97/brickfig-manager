Impostazioni BrickLink

🔑 API BrickLink (opzionale ma consigliata)

Per aggiornare i prezzi reali in automatico, inserisci le credenziali API di BrickLink. Senza, l'app usa scraping + Rebrickable e stima i prezzi.

Ottieni le chiavi qui → bricklink.com/v2/api

🧱 Rebrickable API (alternativa gratuita)

Gratis e subito pronta per recuperare nome/foto anche senza BrickLink. Registrati su rebrickable.com/api.

Altre azioni

Suggerimento: dopo aver inserito un codice, premi Recupera da BrickLink. L'app prova in ordine: 1) Rebrickable API se presente, 2) BrickLink API se configurata, 3) scraping via proxy CORS + immagine diretta img.bricklink.com. Se BrickLink blocca il CORS, la foto viene comunque caricata via URL diretto e il prezzo va inserito manualmente (o stimato).
